=================

版本：0.18.10（2026-09-30 发布）
来源：https://registry.npmjs.org/katex/-/katex-0.18.10.tgz （npm 官方包，非 CDN 转存）

本目录内容
----------
katex.min.css        样式表（24 KB / gzip 3.6 KB），在 zensical.toml 的 extra_css 里
katex.min.js         渲染引擎（约 270 KB），**按需加载**
auto-render.min.js   扫描 DOM 里的 $...$ 并调用渲染（约 3 KB），**按需加载**
fonts/*.woff2        20 个字体子集，共约 296 KB，只有渲染到公式时浏览器才下载
LICENSE              KaTeX 的 MIT 许可证原文

两个加载器脚本的关系
--------------------
docs/others/javascripts/katex.js 是入口（挂在 extra_javascript 里）。它先判断当前页面
正文有没有公式，有才注入 katex.min.js → auto-render.min.js。所以没有公式的页面只多付
一个 24 KB 的 CSS。

只保留了 woff2
--------------
上游 katex.min.css 每个 @font-face 的 src 里依次列了 woff2 / woff / ttf 三种格式，
浏览器只会挑第一个支持的（现代浏览器都是 woff2），所以 woff 和 ttf 永远请求不到，
仓库里就没放（放了要多 900 KB）。真要支持 IE11 之类的老浏览器，再把
fonts/*.woff 拷过来即可，CSS 不用改。

升级步骤
--------
  cd /tmp && rm -rf katex && mkdir katex && cd katex
  curl -fsSL -o katex.tgz https://registry.npmjs.org/katex/-/katex-0.18.10.tgz   # 换版本号
  tar xzf katex.tgz
  cp package/dist/katex.min.css package/dist/katex.min.js ../../docs/others/katex/   # 路径按自己环境改
  cp package/dist/contrib/auto-render.min.js ../../docs/others/katex/
  cp package/dist/fonts/*.woff2 ../../docs/others/katex/fonts/
  cp package/LICENSE ../../docs/others/katex/
然后回归看一眼含公式的页面（tutorial/latex.md、tutorial/matplotlib.md、
tutorial/markdown.md、tutorial/verilog.md 等）渲染是否正常。

破坏性变更提示（0.16 → 0.18）
-----------------------------
0.17 改的是内部 __defineFunction API（只影响注册自定义函数的人，本仓库没用）；
0.18 把内部 CSS 类名加了 katex- 前缀（只影响自己写 CSS 覆盖 KaTeX 内部类的情况，
本仓库 extra.css 里没有任何 katex 选择器）。所以本站升级不需要改代码。
