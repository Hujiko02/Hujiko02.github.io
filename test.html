Tufte 风格的核心不是装饰， 而是把“与正文相关但非必需”的信息——引注、旁白、小图——放到页边， 让读者的视线不必跳到底部。

这一行演示行内引用样式这是一条投注（sidenote）。它带自动编号，编号由 CSS counter 生成，没有 JavaScript。， 注意编号是紧挨着这句话的，而内容写在页边。缩窄窗口到 760px 以下， 边注会折叠成可点击的行内注。

颜色只保留灰阶，彩色留给图表：纸白底 #fffff8、近黑正文 #111。tufte.css 1.9.0 已内置 prefers-color-scheme: dark 暗色模式，无需额外代码。

两种边注

带编号的投注用 sidenote-number编号来自 counter-increment: sidenote-counter， 所以你不必手工写数字，插入删除都不会错位。，编号与内容一一对应， 适合引文出处。

不带编号的叫 margin note宽屏下 margin note 与投注外观相同，只是省略了编号。⊕ 这个符号在宽屏被 label.margin-toggle:not(.sidenote-number) 隐藏，只在窄屏出现，作为展开开关。， 适合与正文没有严格指向关系的旁白，或者干脆放一张小图。

窄屏下投注靠 <label> + 隐藏复选框折叠，这是纯 CSS 方案； 作者明确拒绝用 JS 做这件事，他认为 JS 方案「常常更好」但不在本项目范围内。

表格

宽表必须包一层 div.table-wrapper，否则窄屏会撑破版心。 注意：tufte.css 1.9.0 完全没写表格的边框样式，零边框是它的原生状态， 横线样式由 assets/tufte/local.css 里的第 4 节补上。

本模板相对官方改了什么

  • 新增 assets/tufte/local.css：中文回退字体、CJK 行高、标点挤压、表格横线

  • 示例正文改用 <h2> 而非 newthought，因为中文没有小型大写

要换内容时，保留 <article> 和 <section> 骨架、 保留边注那三件套（label + input + span）的相邻写法，其余随便改。
